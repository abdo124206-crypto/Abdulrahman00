ABDULRAHMAN PORTFOLIO
======================

1) Put your 9 photos in:
   images/
   photo1.jpg
   photo2.jpg
   ...
   photo9.jpg

2) The WhatsApp QR is already included as:
   images/whatsapp-qr.jpg

3) Open index.html in your browser to preview the site.

4) Add a new project:
   Open script.js and add another object inside the `projects` array.
   Example:
   {
     title: "My New Project",
     description: "Short description",
     image: "images/project1.jpg",
     technologies: ["HTML", "CSS", "JS"],
     demo: "https://...",
     github: "https://..."
   }

5) Add more gallery photos:
   Add the image filename to the `gallery` array in script.js.

IMPORTANT:
- Keep file/folder names exactly as written.
- For GitHub Pages, upload the whole folder contents to the repository root.
- This version is intentionally data-driven so adding projects/photos later is easy.
